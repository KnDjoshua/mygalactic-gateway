## 🌟 About The Project

**Cosmic Observatory** is an immersive, interactive web-based educational platform designed to explore fascinating space facts through engaging visual experiences and dynamic content. This project demonstrates mastery of modern web technologies while providing an enjoyable learning environment about our universe.

### 🎯 Project Purpose

This project was developed as a **university course project** to demonstrate:

- ✅ Proficiency in **HTML5 semantic structure**
- ✅ Mastery of **advanced CSS3 animations** (keyframes, transitions, transforms)
- ✅ Implementation of **dynamic JavaScript functionality** (ES6+ features)
- ✅ Building **secure PHP backend** with validation and CSRF protection
- ✅ Creating **responsive, mobile-first design** that works on all devices
- ✅ Delivering **engaging user experience** with interactive elements

### 🎮 Live Demo Features

| Feature | Description |
|---------|-------------|
| **Star Particle System** | 200+ dynamically generated animated stars |
| **3D Knowledge Cards** | Flip-to-reveal interactive fact cards |
| **Animated Statistics** | Count-up numbers triggered on scroll |
| **Dynamic Fact Filtering** | Filter space facts by category |
| **Infinite Scroll Facts** | Load more content dynamically |
| **Custom Cursor** | Interactive cursor with hover effects |
| **Glitch Text Hero** | Attention-grabbing animated title |
| **Parallax Scrolling** | Depth perception while scrolling |

- Infinite scroll for loading more facts
- Animated statistics counters with Intersection Observer
- Custom cursor with follower effect
- Interactive navigation with smooth scroll
- Hover effects on all clickable elements
- Loading screen with orbital animation

- Adaptive layouts for all screen sizes
